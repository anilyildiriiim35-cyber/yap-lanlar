### 🎨 CSS ve HTML Ayrıldı

* Sayfa içindeki `<style>` blokları kaldırıldı
* Tüm tasarım kodları `assets/css/style.css` dosyasına taşındı
* HTML dosyaları sadece yapı (structure) içerecek şekilde sadeleştirildi
* Sayfalara harici CSS bağlantısı eklendi

```html
<link rel="stylesheet" href="assets/css/style.css">
```

* `pages` klasöründeki sayfalar için doğru path kullanıldı:

```html
<link rel="stylesheet" href="../assets/css/style.css">
```
